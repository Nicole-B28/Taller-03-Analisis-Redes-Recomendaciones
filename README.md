Taller 03: Análisis de Redes y Sistemas de Recomendación

Descripción

Este proyecto desarrolla un análisis de redes y un sistema de recomendación utilizando el conjunto de datos MovieLens 100K, como parte de un trabajo académico de la Maestría en Ciencia de Datos.

Objetivos

Analizar las relaciones entre usuarios y películas mediante grafos bipartitos.

Identificar propiedades de la red y explorar comunidades con Girvan-Newman.

Implementar modelos de recomendación mediante SVD y KNN.

Evaluar y optimizar los modelos utilizando RMSE y GridSearchCV.

Generar recomendaciones personalizadas de películas.

Tecnologías utilizadas

Python

Google Colab

Pandas

NetworkX

Matplotlib

Scikit-Surprise

Scikit-learn

Conjunto de datos

Se utiliza MovieLens 100K, que contiene 100.000 calificaciones de 943 usuarios sobre 1.682 películas.
